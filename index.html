Real-time AI Video Companion · 项目演示

自己做了个小工具：看英文视频时把字幕实时翻成中文，看不懂的句子还能直接追问；后来顺手加了个「跨境直播模式」，把外服队友的英文对话翻成中文浮窗，直播时单独给观众看。

查看 GitHub 源码 → 下载视频（约 9 MB）

这个工具做了什么

① 看英文 YouTube 视频

优先读取视频自带英文字幕，没有才切实时语音识别；英文先展示、中文异步回填，双语记录可以回看，遇到不懂的句子能基于视频上下文直接追问。

② 跨境直播模式

采集本机麦克风与系统声音，英文识别后翻成中文，用和插件同款的白卡片浮窗显示在桌面；浮层可拖动、收起，在 OBS 里单独叠加给国内观众看。

  • 两个场景复用同一条 ASR → 断句 → 翻译 → 上下文问答链路，直播模式是在原有桌面端上增量加的一个按钮，没有重写 AI 管线。
  • 仓库 README 有完整功能与效果图，LIVE_MODE.md 记录了直播模式的架构、实测数据与已知边界。
  • 验证口径：真实 API 链路 13/13、英文语音闭环 3.28 s、直播全链路 5.25 s、86/86 单测；多人抢话、连续 2 小时长播与真实账单仍在待验证清单里。
