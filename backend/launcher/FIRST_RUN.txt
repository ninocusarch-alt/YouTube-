Real-time AI Video Companion 首次使用
=====================================

推荐方式：双击 VideoCompanionSetup.exe 完成当前用户安装，不需要管理员权限。

安装后：
1. 从桌面或开始菜单打开 Real-time AI Video Companion。
2. 首次运行时，在弹出的窗口粘贴千问 API Key 并保存。
3. 等待窗口显示“服务已就绪”。
4. 点击“安装 / 更新 Chrome 插件”，按照浏览器页面完成首次加载。
5. 打开 YouTube 英文视频并开始播放。
6. 点击 Chrome 插件中的“打开视频双语助手”。

使用期间请保持启动器窗口运行，可以最小化，但不要关闭。
如希望登录 Windows 后自动准备服务，可点击“开机启动：关闭”将其切换为开启。
API Key 只保存在本文件夹的 .env 中，请勿截图、上传或分享。

如果插件提示无法连接后端，请先查看启动器窗口的状态和错误信息。
